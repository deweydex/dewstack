How this course works

This course has two halves. In the first half, we build a website in HTML and CSS and publish it on GitHub Pages. In the second half, we work with databases: tables, SQL queries, and a little Python.

The four steps below are in the order that works. Step 1 is where most of the learning happens. Steps 2 and 3 hold the things you will need along the way. Step 4 is what the course asks you to submit.

Step 1: Build your own site

You start with three files. You end with a portfolio site that is published on the web, at an address you can share, built by you.

The three files are a home page, an about page, and a stylesheet. The code is full of comments that say what each part does. The README of the repository is a list of 25 short exercises. Each exercise asks you to change one thing, save, and look at the result.

First, you fork the repository and turn on GitHub Pages. Your site is published from the second exercise, so every change you make is visible at a real address. Then you work through your home page: the heading, your introduction, a skills section, an image, links, and navigation. Then you explore the stylesheet: colours, the box model, borders, and text. Then you work on layout, a sticky header, and a footer. Last, you add hover effects, focus states, and a design that works on a phone.

Step 2: Tutorials, guides, and templates

The exercises in Step 1 show you what happens. The tutorials explain why. Use them when an exercise leaves you with a question, or when you want more practice.

There are thirteen lessons. Lessons 1 to 10 cover the same ground as the exercises, in more depth. Lessons 11 to 13 cover Flexbox, Grid, components, and animation. You will need those three for the web authoring project.

The same site has seven step-by-step GitHub guides, four small example pages, eleven starter templates, a troubleshooting page, and a quick reference.

Open the tutorials

  • The tutorials front page, with all thirteen lessons in order
  • Lesson 11: Flexbox and Grid, the first of the three for the project
  • GitHub guides, from making an account to publishing a site
  • Starter templates and example pages
  • Troubleshooting, for when something does not work and you cannot see why
  • Quick reference for HTML tags and CSS properties

Step 3: Databases

A database keeps information in tables. SQL is the language you use to ask a table a question. Everything in this step runs inside your browser. Nothing is installed, and nothing you type is sent anywhere.

Start with the playground. It has short refreshers on HTML and CSS, then SQL: SELECT, WHERE, ORDER BY, INSERT, UPDATE, DELETE, and COUNT. Then try the quiz. The notebook covers the same ideas in Python, and adds joining two tables.

Open the database pages

  • The SQL playground: type a query, run it, and see the result
  • The SQL quiz: practice questions on a small shop database
  • The SQLite notebook, opened in Google Colab, or the notebook file to download
  • The playground, teacher version, with solutions and notes

Step 4: Projects and the exam

The college sets the assessments: a web authoring project, a database project, and a practical exam. The briefs and the dates are on your course page and on Moodle. We go through each brief in class before it is due.

The web authoring project builds on your site from Step 1. Lessons 11 to 13 and the templates in Step 2 are written for it. The database project builds on Step 3.
