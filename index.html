Web Authoring and Databases

Tutorials, guides and templates for the Level 5 Web Authoring and Database Methods modules

This site has two halves. In the first half, you build a website in HTML and CSS and publish it on GitHub Pages. In the second half, you work with databases: tables, SQL queries and a little Python.

Start with your own site. Come back here whenever you need a guide, a template, a longer explanation, or a place to practise SQL.

Start Here: Build Your Own Site

The quickest way to learn HTML and CSS is to change a real page and watch what happens.

We have a starter site for exactly that. It is a small portfolio with three files: a home page, an about page and a stylesheet. The code is full of comments that explain what each part does. Its README is a list of numbered exercises. Each exercise asks you to change one thing, save, and look at the result.

Here is how to begin. First, fork the starter repository on GitHub. Then turn on GitHub Pages in your fork's settings. Then open the README and start at exercise 1. Your site is live from the second exercise, so every change you make is visible at a real web address.

Fork the Starter See the Starter Site How to Turn On GitHub Pages

How to Use This Site

There is an order that works, and it is not front to back.

First, fork the starter and do its exercises. That is where most of the learning happens. Second, when an exercise raises a question, read the lesson that answers it. Third, when you begin the web authoring project, read lessons 11 to 13 and look at the templates. Fourth, when the module turns to databases, open the playground.

The GitHub guides are step-by-step instructions. Use them the moment you need them, and come back to them as often as you like. The troubleshooting page is for when something does not work and you cannot see why. That happens to everyone.
