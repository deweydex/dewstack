Study Sheet - Quick Reference

1. SQL Data Types

When creating tables, you need to specify what type of data each column will hold:

Data Type Description Example Values
TEXT Stores text/string data of any length 'Maya Chen', 'Computing', 'Dublin'
INTEGER Stores whole numbers (positive or negative) 20, 5, -3, 0, 100
REAL Stores decimal numbers (floating point) 3.5, 12.75, -2.3, 0.99
BLOB Stores binary data (images, files) Binary data (rarely used in basic SQL)
NULL Represents missing or unknown data NULL (no value)

Note: SQLite is flexible with data types. If you use VARCHAR(50) or CHAR(10), they will be treated as TEXT.

2. Creating Tables

Use the CREATE TABLE statement to define a new table:

CREATE TABLE table_name (
    column1 datatype,
    column2 datatype,
    column3 datatype
);

3. Adding Data (Inserting Records)

Use INSERT INTO to add data:

INSERT INTO table_name (column1, column2, column3)
VALUES ('value1', 'value2', value3);

For multiple rows at once:

INSERT INTO table_name (column1, column2)
VALUES 
    ('value1', 'value2'),
    ('value3', 'value4'),
    ('value5', 'value6');

4. Filtering Data (Querying)

Use SELECT with WHERE to filter:

SELECT * FROM table_name WHERE condition;

Examples of conditions:

  • column_name = 'value' - exact match
  • column_name > 100 - greater than
  • column_name >= 20 - greater than or equal to
  • column_name < 50 - less than
  • column_name LIKE '%text%' - contains text

5. Deleting Data

Use DELETE FROM with a WHERE clause:

DELETE FROM table_name WHERE condition;

Warning: Without a WHERE clause, ALL rows will be deleted.

Quiz Tasks

Complete the following tasks in order. Type your SQL commands in the editor below and click "Run SQL" to execute them.

Task 1: Create Two Tables

Create two tables in your database with the following structure:

  • students table with columns:
    • name (TEXT)
    • age (INTEGER)
    • programme (TEXT)
  • modules table with columns:
    • module_name (TEXT)
    • hours_per_week (INTEGER)
    • lecturer (TEXT)
Requirements: Both tables must exist with the exact column names and data types specified above. Note: "programme" is spelled the Irish/British way.

Task 2: Add Data to Both Tables

Insert exactly 3 records into each table:

students table - Add these 3 students:
  • Maya Chen, age 19, programme Computing
  • Fatima Al-Rahman, age 22, programme Business
  • Kofi Mensah, age 20, programme Design
modules table - Add these 3 modules:
  • Programming Fundamentals, 5 hours per week, lecturer Dr. Walsh
  • Database Methods, 4 hours per week, lecturer Ms. Patel
  • Web Development, 6 hours per week, lecturer Mr. O'Sullivan

Task 3: Filter Data - First Query

Write a SELECT query to find all students whose age is greater than or equal to 20.

Requirements: Use a WHERE clause with the >= operator. This should return Fatima Al-Rahman and Kofi Mensah.

Task 4: Filter Data - Second Query

Write a SELECT query to find all modules with 5 or more hours per week.

Requirements: Use a WHERE clause with the >= operator. This should return Programming Fundamentals and Web Development.

Task 5: Delete an Entry

Delete the student named "Maya Chen" from the students table.

Requirements: Use DELETE FROM with a WHERE clause that targets name = 'Maya Chen'. After deletion, only 2 students should remain.
