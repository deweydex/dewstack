# Teacher Lesson Plan Template

This template provides structured lesson plans for teaching HTML, CSS, and SQL using this interactive tutorial. Choose the format that fits your class structure.

---

## Quick Reference: Class Duration Options

- **1-Hour Workshop** - Introduction to all three technologies
- **3-Hour Workshop** - Hands-on practice with each technology
- **5-Session Course** (1 hour each) - Comprehensive coverage
- **10-Session Course** (1 hour each) - Deep dive with projects
- **Full Semester** (14 weeks) - Complete web development course

---

## One-Hour Workshop: Web Technologies Sampler

**Target Audience:** Beginners with no experience  
**Goal:** Introduce HTML, CSS, and SQL basics  
**Format:** Demo-heavy with limited hands-on

### Timing Breakdown

**0:00-0:10 | Welcome & Setup (10 min)**
- Introduce yourself and the session
- Have students open the tutorial (link or local file)
- Verify everyone can see the page
- Quick poll: "Who has written any code before?"

**0:10-0:20 | HTML Basics (10 min)**
- Navigate to HTML section together
- Explain: "HTML is the skeleton of web pages"
- Point out the form example
- Have students fill out the form
- Briefly show HTML code for the form
- Key takeaway: Tags create structure

**0:20-0:30 | CSS Styling (10 min)**
- Navigate to CSS section
- Explain: "CSS is the skin - it makes things look good"
- Show the box model visual
- Open DevTools (F12) and modify colors live
- Key takeaway: CSS controls appearance

**0:30-0:55 | SQL Queries (25 min)**
- Navigate to SQL section
- Explain: "SQL stores and finds data"
- Click "Show All Students" button together
- Have students click other example buttons
- Guide through Exercise 1 as a class
- Students try Exercise 2 independently (5 minutes)
- If time: Exercise 3
- Key takeaway: SQL lets you ask questions about data

**0:55-1:00 | Wrap-up & Resources (5 min)**
- Recap: HTML (structure) + CSS (style) + SQL (data)
- Show "Next Steps" section
- Share link to tutorial for further practice
- Q&A

### Materials Needed
- Tutorial accessible (online link or downloaded files)
- Projector for demonstration
- Computer lab or student devices

### Assessment
- Participation observation
- Optional exit ticket: "Write one thing you learned about SQL"

## Three-Hour Workshop: Hands-On Web Development

**Target Audience:** Beginners to intermediate  
**Goal:** Complete all core exercises  
**Format:** Balanced lecture and practice

### Hour 1: HTML Foundation

**0:00-0:15 | Introduction & HTML Basics**
- Course overview and objectives
- What is HTML? (lecture)
- HTML structure demonstration
- View page source together

**0:15-0:30 | HTML Tags**
- Common tags lecture
- Form elements walkthrough
- Try the sample form

**0:30-0:45 | HTML Practice**
- Students create simple HTML page in text editor
- Must include: heading, paragraph, list
- Walk around and help

**0:45-1:00 | HTML Review & Discussion**
- Share examples
- Troubleshoot common issues
- Q&A

### Hour 2: CSS Styling

**0:00-0:15 | CSS Introduction**
- What is CSS? (lecture)
- Three ways to add CSS
- CSS syntax walkthrough

**0:15-0:30 | The Box Model**
- Box model explanation (critical!)
- DevTools demonstration
- Margin vs padding activity

**0:30-0:45 | CSS Practice**
- Students style their HTML page from Hour 1
- Must include: colors, fonts, spacing
- Bonus exercises available for fast finishers

**0:45-1:00 | CSS Gallery Walk**
- Students share their styled pages
- Peer feedback
- Discuss design choices

### Hour 3: SQL Queries

**0:00-0:15 | SQL & Databases Intro**
- What is SQL? (lecture)
- Database table visualization
- Our sample database walkthrough

**0:15-0:30 | SQL Commands**
- SELECT demonstration
- WHERE clause examples
- ORDER BY examples

**0:30-0:50 | SQL Exercises**
- Students complete Exercises 1-5
- Work independently with hints
- Teacher circulates and helps

**0:50-1:00 | Wrap-up & Challenge**
- Share interesting queries
- Bonus exercises for interested students
- How it all connects discussion

### Materials Needed
- Text editor (Notepad++, VS Code, or Sublime)
- Tutorial open in browser
- Printed hint sheets (optional)

### Assessment
- Completion of exercises
- Code review during practice
- Understanding demonstrated in discussions

## Five-Session Course: Web Development Fundamentals

**Format:** Five 1-hour sessions  
**Level:** Beginner  
**Prerequisite:** None

### Session 1: HTML Structure

**Learning Objectives:**
- Understand HTML document structure
- Use common HTML tags appropriately
- Create a basic web page

**Activities:**
1. HTML basics lecture (15 min)
2. Tutorial walkthrough (10 min)
3. Build "About Me" page (25 min)
4. Share and discuss (10 min)

**Homework:** Add 3 more sections to "About Me" page

**Assessment:** Completed HTML page with proper structure

---

### Session 2: CSS Fundamentals

**Learning Objectives:**
- Apply CSS to HTML elements
- Understand the box model
- Use colors and fonts effectively

**Activities:**
1. CSS introduction (15 min)
2. Box model deep dive (15 min)
3. Style "About Me" page (20 min)
4. Pair review (10 min)

**Homework:** Complete Bonus Exercise C1 (Color Your Page)

**Assessment:** Styled page using proper CSS syntax

---

### Session 3: SQL Basics - Reading Data

**Learning Objectives:**
- Understand database tables
- Write SELECT queries
- Filter data with WHERE
- Sort data with ORDER BY

**Activities:**
1. Database concepts (10 min)
2. SQL playground demo (10 min)
3. Complete Exercises 1-3 (30 min)
4. Review solutions (10 min)

**Homework:** Write 5 custom SELECT queries

**Assessment:** Completed exercises with correct syntax

---

### Session 4: SQL Advanced - Changing Data

**Learning Objectives:**
- Insert new records
- Update existing data
- Delete records safely
- Use aggregate functions

**Activities:**
1. INSERT/UPDATE/DELETE lecture (15 min)
2. Safety discussion (5 min)
3. Complete Exercises 4-5 (25 min)
4. Bonus challenges (15 min)

**Homework:** Design your own database table

**Assessment:** Safe and correct data manipulation

---

### Session 5: Integration & Projects

**Learning Objectives:**
- Understand how HTML, CSS, and SQL work together
- Complete a small project
- Reflect on learning

**Activities:**
1. "Putting It All Together" discussion (15 min)
2. Project work (35 min)
   - Create a page showcasing SQL queries
   - Style it with CSS
3. Presentations (10 min)

**Final Project:** Styled HTML page with embedded SQL results

**Assessment:** Complete project + reflection

## Differentiation Strategies

### For Struggling Students:

**Scaffolding:**
- Provide starter code
- Pair with stronger student
- Break exercises into smaller steps
- Focus on exercises 1-3 only
- Extra hints available

**Example Modifications:**
- Exercise 1: Provide partial query
- Exercise 2: Give exact WHERE clause structure
- Exercise 3: Fill-in-the-blank INSERT statement

### For Advanced Students:

**Extensions:**
- Bonus exercises (HTML & CSS bonus file)
- Create your own database tables
- Learn about JOINs
- TypeScript version
- Build a real project

**Challenge Projects:**
- Build a complete website
- Add JavaScript interactivity
- Connect to external API
- Design database schema for complex scenario

**Visual Learners:**
- Box model diagram
- Color-coded syntax
- DevTools demonstration

**Auditory Learners:**
- Explain code aloud
- Pair programming discussions
- Class discussions
- Peer teaching

- Hands-on coding

## Common Challenges & Solutions

### Challenge: Students at Different Paces

**Solution:**
- Tier exercises (minimum, expected, bonus)
- Fast finishers help others (peer teaching)
- Bonus exercises always available
- Self-paced progression with checkpoints

### Challenge: Technical Issues

**Solution:**
- Test all computers before class
- Have offline version ready
- Backup plan (paper exercises)
- IT contact information handy

### Challenge: Engagement

**Solution:**
- Real-world examples
- Student choice in projects
- Gamification (points, badges)
- Show cool websites and explain how they work

### Challenge: Abstract Concepts

**Solution:**
- Use analogies (HTML = skeleton, CSS = clothes)
- Physical demonstrations (box model with boxes)
- Lots of examples
- Let students discover through experimentation

## Sample Lesson Plan (Detailed)

### Topic: SQL SELECT Queries
**Duration:** 50 minutes  
**Level:** Beginner

**Learning Objectives:**
By the end of this lesson, students will be able to:
1. Write basic SELECT queries to retrieve data
2. Use WHERE clause to filter results
3. Use ORDER BY to sort data
4. Explain what each part of a query does

**Materials:**
- Tutorial open on all computers
- Projector for demonstration
- Printed reference sheet (optional)

**Lesson Flow:**

**1. Hook (5 minutes)**
"How does Netflix find movies for you? How does Google find websites? Today we learn SQL - the language that finds data."

Show examples:
- Netflix finding all comedy movies
- Amazon finding products under $20
- Instagram finding your friends' photos

**2. Introduction (10 minutes)**

**Explain databases:**
- Draw table on board
- Show how data is organized in rows and columns
- "Just like a spreadsheet, but with superpowers"

**Navigate to SQL section:**
- Show students table
- Click "Show All Students" button
- Examine results together

**Basic SELECT syntax:**
```sql
SELECT what_you_want FROM where_it_is;
```

**3. Guided Practice (15 minutes)**

**Example 1: Select specific columns**
- Write on board: `SELECT name, age FROM students;`
- Explain each part
- Students type and run
- Discuss results

**Example 2: Filter with WHERE**
- Write: `SELECT * FROM students WHERE age > 20;`
- Explain comparison operators
- Students type and run
- "How many results? Why these students?"

**Example 3: Sort with ORDER BY**
- Write: `SELECT * FROM students ORDER BY grade DESC;`
- Explain ASC vs DESC
- Students experiment with both

**4. Independent Practice (15 minutes)**

Students complete Exercise 1 and 2:
- Exercise 1: Select name and age
- Exercise 2: Find students with grade < 75

Teacher circulates and helps
Monitor who finishes quickly (they get Exercise 3)

**5. Review & Closing (5 minutes)**

**Ask for volunteers:**
- "Who wants to share their query for Exercise 2?"
- Write on board
- Class verifies correctness

**Key takeaways:**
- SELECT tells what to get
- FROM tells where to get it
- WHERE filters results
- ORDER BY sorts results

**Preview next class:**
"Next time: How to ADD, UPDATE, and DELETE data!"

**Exit Ticket:**
"Write a query to find all students aged exactly 20"

## Customization Tips

**Adapt for your students:**
- Change examples to student interests
- Use school-relevant data in SQL
- Connect to other subjects
- Include cultural references students know

**Adapt for your schedule:**
- Break lessons into smaller chunks
- Combine topics if time is limited
- Extend with projects if time allows
- Flip classroom (videos at home, practice in class)

**Adapt for your resources:**
- Cloud-based (GitHub Pages) if computers limited
- Printed exercises if internet unreliable
- Pair programming if not enough computers
- Demo-only if no computer lab access
