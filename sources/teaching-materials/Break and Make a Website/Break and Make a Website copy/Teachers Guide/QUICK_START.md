# Quick Start Guide

## Get Started in 5 Minutes

### Step 1: Open the Project
1. Make sure all 4 files are in the same folder:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `README.md`

2. Double-click `index.html` to open in your browser

### Step 2: Explore
Move the sliders and watch what happens!
- Tax brackets affect when rates change
- Tax rates control how much tax people pay
- Tax credit reduces everyone's tax bill
- PRSI is a flat rate social insurance

### Step 3: Open the Code
Open all three code files in a text editor (VS Code recommended)

### Step 4: Make Your First Change
**In `styles.css`, find line 74:**
```css
header {
    padding: 1rem 0;
    text-align: center;
    /* background-color: #4C72B0; */  ← Remove the /* */ to uncomment!
}
```

Save the file and refresh your browser. The header should now be blue!

## Try These Exercises Next

### Easy (CSS):
1. Change the blue button color (`#4C72B0`) to your favorite color
2. Make the main heading bigger (`h1` element)
3. Add rounded corners to the container (use `border-radius`)

### Medium (HTML):
1. Add a new paragraph explaining what PRSI is
2. Change the text on the reset button
3. Add a footer with your name

### Hard (JavaScript):
1. Uncomment the `calculateAverageTaxPerPerson()` function (line ~505)
2. Call it from `recalculateAll()` 
3. Display the result in the summary

## Something Broken?
1. Press `F12` to open developer tools
2. Look at the "Console" tab for error messages
3. Check that all files are in the same folder
4. Make sure you saved your changes
