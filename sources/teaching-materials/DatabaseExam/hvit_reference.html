Database
An organised collection of structured data stored so it can be efficiently retrieved and updated. SQLite stores a database as a single file on disk.
Table
A grid of data inside a database, similar to a spreadsheet. Each table has a fixed set of columns and any number of rows.
Row / Record
One entry in a table — a single set of values for each column. Adding a student or an item to a database creates a new row.
Column / Field / Attribute
A named property shared by every row in a table. Each column has a data type (TEXT, INTEGER, REAL) that determines what kind of value it can hold.
Primary Key PK
A column (or combination of columns) whose value uniquely identifies each row. No two rows can share the same primary key value, and it cannot be NULL. Often called id or table_name_id.
NULL
A special marker meaning "no value" or "unknown". NULL is not the same as zero or an empty string. In SQL, use IS NULL or IS NOT NULL to check for it.
SQL — Structured Query Language
The standard language used to interact with relational databases. SQL statements describe what data you want; the database engine works out how to retrieve it.
Query
A request sent to the database — usually a SELECT statement that asks for specific rows or a summary. Queries read data without changing it.
SELECT
The SQL keyword that retrieves data from a table. SELECT * returns all columns; listing specific column names returns only those.
WHERE clause
A filter added to a SELECT (or INSERT/UPDATE/DELETE) that limits which rows are affected. Only rows where the condition evaluates to true are included.
ORDER BY
Sorts the result of a query. ORDER BY column_name sorts ascending (A→Z, 0→9); adding DESC reverses the order.
GROUP BY
Collapses many rows into summary groups based on a shared value. Always used alongside an aggregate function such as COUNT, SUM, or AVG.
Aggregate function
A function that computes a single result from a set of rows: COUNT(*) counts rows, SUM(col) adds values, AVG(col) calculates the average, MAX and MIN find extremes.
INSERT
The SQL statement that adds a new row to a table. The values provided must match the column order or be named explicitly.
commit()
Confirms and permanently saves all changes made since the last commit. Without calling conn.commit(), INSERT and UPDATE changes are lost when the connection closes.
Transaction
A group of database operations treated as a single unit. Either all succeed (and are committed) or all are rolled back, keeping the database consistent.
PRAGMA
A special SQLite command that returns information about the database itself rather than its data. PRAGMA table_info(table_name) lists the columns of a table.
DataFrame
The main data structure in pandas — a two-dimensional table with labelled rows and columns. Returned by pd.read_sql() and pd.read_excel().
Boolean filter
A way of selecting rows from a DataFrame by writing a condition that evaluates to True or False for each row. Written as df[df['column'] == value].
Connection / cursor
The connection (conn) represents the open link to a database file. The cursor (cursor) is the object you use to send SQL statements and retrieve results.
JOIN
A SQL operation that combines rows from two or more tables based on a matching column value. Useful when related data is split across tables.

# That function runs every time the button is clicked
@button("Submit")
def submit():
    cursor.execute(
        "INSERT INTO table_name (name, category) VALUES (?, ?)",
        (item_name.value, category.value)
    )
    conn.commit()
    show(f"Saved: {item_name.value} — {category.value}")
    item_name.clear()   # clear the text field after saving
