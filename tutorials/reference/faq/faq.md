# FAQ

Quick answers to the questions people ask most before or during this
course. [Troubleshooting](tutorial:troubleshooting) is the page for
something that is actually broken — this page is for the questions that
come before that.

## Do I need to know how to code before I start?

No. The starter repository and the tutorials both start from nothing, and
build up one exercise at a time.

## Do I need to install anything?

Not for the data track. For the web track, you need a text editor. VS Code
is free and works on any computer. If you cannot install programs, GitHub
has an editor built into its own website, and every exercise works there
too.

## Is this graded?

The tutorials and exercises themselves are not. Only the two projects and
the exam are, and your teacher covers the dates and the briefs for those in
class. Breaking something and fixing it while you are still learning costs
nothing here.

## Which track should I start with?

Either. The website track teaches HTML and CSS and ends in a site you
publish. The data track teaches tables and SQL and ends in a database you
can query. If you are in a class, your teacher will say which comes
first; if you are working on your own, pick whichever interests you more.

## What if I fall behind, or miss a class?

Each page is short and stands mostly on its own. Picking a series back up
after a gap costs you re-reading one page, not the whole thing. Search
the tutorials for the topic by name if a word has gone unfamiliar in the
meantime.

## Can I use this on a phone?

Yes, for reading the tutorials. The web track's own editing is easier on a
computer, since it needs a text editor and a browser open side by side.

## My teacher wants something different from what is written here. What do I do?

Follow your teacher. The college sets the projects and the exam, and this
site is one way through the material behind them, not the only way.

## What happens to my work once the course is over?

If you started with a website, it stays in your own GitHub repository for
as long as you keep the account. It is yours, not the college's. In the
playground, nothing is kept between visits unless you copy a query
somewhere of your own.

## Something here is actually broken. What do I do?

[Troubleshooting](tutorial:troubleshooting) groups the problems people
meet most often: a blank page, styles that will not apply, GitHub not
taking a push. Each one comes with the checks that usually find it.
