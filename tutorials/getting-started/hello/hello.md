# Hello

This is the first page of the tutorials. It shows you how a page here is
laid out, so that nothing on the later pages is a surprise.

## What is on every page

At the top of every page there is a bar that stays in view while you
scroll. On the left is the word **dewadaba**. Clicking it takes you back
to the list of tutorials. On the right is the **Settings** button.

Under that bar there are links to the previous page and the next page.
The same links appear again at the bottom.

## Settings

The Settings button opens a panel. In it you can choose a light or dark
theme, a typeface, a text size and a line width. Two of the typefaces are
designed for readers who find ordinary text hard to read. One is called
Atkinson Hyperlegible. The other is called OpenDyslexic. Try them and keep
whichever suits you.

Your choices are saved in this browser. They follow you from page to page.
Nothing you choose is sent anywhere.

## Code on a page

Some pages show code. It appears in a box like this one.

```sql
SELECT name, price
FROM products
WHERE price < 20;
```

For now the boxes only show code. Pages where you can change the code and
run it are planned for later.

## Where to go next

The list of tutorials is one click away, on the word **dewadaba** at the
top of the page. New tutorials will appear there as they are written.
